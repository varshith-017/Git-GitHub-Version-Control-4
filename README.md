
# DevOps Internship Task 4
## Git and GitHub Version Control Project

### Project Overview
This project demonstrates Git and GitHub version control
best practices through a simple interactive website.

### Objective
To understand repository management, commits,
branching, merging, Pull Requests and Git tags.

### Technologies Used
- Git
- GitHub
- HTML
- CSS
- JavaScript
- Visual Studio Code

### Project Structure
- index.html - Main webpage
- style.css - Website styling
- script.js - JavaScript functionality
- README.md - Project documentation
- .gitignore - Ignored files
- docs/git-workflow.md - Git documentation

### Branches
- main - Stable version
- dev - Development version
- feature/add-project-feature - Feature development

### Git Operations
1. Git repository initialization
2. Initial commit
3. Development branch creation
4. Feature branch creation
5. Feature implementation
6. Push branches to GitHub
7. Create Pull Requests
8. Merge feature into dev
9. Merge dev into main
10. Create Git tag v1.0

### Run Project
Open index.html in any web browser.

### Version
v1.0

### Conclusion
Successfully demonstrated Git and GitHub
version control workflow as part of DevOps Internship Task 4.
