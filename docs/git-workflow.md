
# Git Workflow Documentation

## 1. Git Initialization
Initialized the project using git init.

## 2. Main Branch
The main branch maintains the stable project version.

## 3. Development Branch
The dev branch is used for development activities.

## 4. Feature Branch
The feature branch is used to develop new functionality.

## 5. Commit Management
Git commits track changes made to project files.

## 6. Pull Requests
Pull Requests are used to review changes before merging.

## 7. Merge Process
Feature branch changes are merged into dev.
The dev branch is then merged into main.

## 8. Git Tags
The v1.0 tag identifies the first stable release.

## 9. Git Stash
Git stash temporarily stores uncommitted changes.

## 10. Conclusion
Git and GitHub help maintain project history,
collaboration and version control.
